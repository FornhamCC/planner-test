Key help — the editing key

Why there is a key Renewing it each year If it has expired Making a new key Keeping it safe

1. Why there is a key

Members only read the board, so they need no account and no key.

Saving a change means writing to the plan file kept on GitHub, and GitHub only allows that with proof of who you are. The key is that proof. It is made in your GitHub account and pasted into the board once on each device you edit from.

  • It works only for the planner and planner-test repositories, and only for their files. It cannot touch anything else in your GitHub account.
  • It expires (after a year), so a key that is lost or forgotten stops working by itself.
  • Each device remembers it. It is sent only to GitHub and is never stored in the plan.

2. Renewing it before it expires about 5 minutes

GitHub emails you about a week before the key expires, and the board shows a reminder from 30 days before.

  1. Press Open my keys on GitHub below and sign in if asked.
  2. Under Fine-grained tokens, choose the planner key.
  3. Press Regenerate token. Choose the same expiry as before (a year), then confirm.
  4. Press the copy button next to the new key straight away. GitHub shows it only once. Keeping a copy in your password manager is a good idea.
  5. On each device you edit from (PC and iPad): open the board, then Settings → Paste new key, paste it and press Unlock.

The old key stops working the moment you regenerate, so a device that still has it will ask for the new one. Nothing is lost.

3. If it has already expired

The board goes view-only and shows a Paste new key box. Changes not yet saved stay on that device and save once the new key is in.

Regenerate the key as in section 2 (an expired key can still be regenerated), then paste it on each device.

4. Making a brand-new key

Only needed if the old key was deleted on GitHub. In your keys on GitHub, press Generate new token under Fine-grained tokens, and choose:

Token name
Planner (any name you will recognise)
Resource owner
FornhamCC (not your own name)
Expiration
A year (the longest offered)
Repository access
Only select repositories: planner and planner-test
Permissions
Repository permissions → Contents: Read and write (nothing else)

Press Generate token, copy it at once, and paste it into the board on each device. The setup guide has the same steps with more detail.

5. Keeping it safe

  • Paste it only into the board (and your password manager). Never email or message it.
  • If you think someone has seen it, or a device is lost, regenerate it on GitHub: the old key stops working at once.
  • Settings → Remove key from this device makes that device view-only again.
