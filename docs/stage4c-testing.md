# Stage 4c — testing guide (simple PDF choices)

The **PDFs** page now asks up to three short questions, each answered with a large button:

| Step | Buttons | Then |
| --- | --- | --- |
| **1. Which group?** | **Great Barton** · **Fornham** · **Both** (short names from Settings → Clubs) | A club → step 2. **Both** → the whole plan, straight to step 3. |
| **2. Which session?** | Windows Beginners · Windows Main · iPad Beginners · iPad Main, in their board colours · **All four** | One group → its list (portrait). All four → the club's four groups side by side (landscape). |
| **3. Which year?** | **‹ 2026 ›** — starts on the current year; the arrows step through the years the board covers | **Make PDF** |

A line under the heading shows the choices so far (e.g. *Fornham › FCC iPad Beginners*), and **Back** goes one step back. The briefing tickbox appears only for a single group. The PDFs themselves are exactly the same as before.

*Wording updated 19 Oct 2026 (Nice to Have 15): the clubs are called "groups" by their short names and the four sub-groups "sessions", so the page still reads correctly if the clubs merge under one name. Change the short names in Settings → Clubs.*

**More options…** (top right) opens the full page from Stage 4a: separate months, Windows-only or iPad-only whole plans, all eight groups in one file or as eight files. **Simple choices** on that page returns to step 1.

Only `index.html` and this guide change. Claude has pushed them to **planner-test**; nothing on the live board has changed.
